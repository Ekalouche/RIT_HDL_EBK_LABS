# VHDL Full Adder — Behavioral and Structural Design

This lab implements a one-bit full adder in VHDL using two design approaches: a behavioral description and a structural hierarchy assembled from AND, OR, and XOR gates.

## Highlights

- Models the same Boolean function with behavioral and structural architectures
- Builds reusable gate-level components
- Uses self-contained testbenches to verify input combinations
- Compares abstraction levels in digital hardware design

## Repository Layout

- `full_adder_single_bit_beh/` — behavioral implementation and testbench
- `full_adder_single_bit_struc/` — structural implementation, component gates, and testbench
- `lab1.pdf` — original lab reference

## Tools and Skills

VHDL, ModelSim, combinational logic, component instantiation, hierarchical design, and testbench development.
